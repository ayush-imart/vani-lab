# UI follow-up: typography hierarchy

## Finding

The app does not have a clear, consistent hierarchy of font sizes across its screens. Page titles, section headings, card labels, KPI values, table text, and supporting copy can feel too similar in size, making it harder to scan the interface.

## Follow-up

- Audit the main screens together: setup, performance, pipeline, prompts, scorecard, and scale-up.
- Define a small type scale for page titles, section headings, card titles, KPI values, body text, labels, and helper text.
- Apply it consistently while preserving the existing semantic color and spacing tokens.
- Check dense screens and narrow viewports so supporting text remains readable.

This is a visual-design follow-up, not part of the current deployment work.
